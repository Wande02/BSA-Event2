# BSA 2026 Attendee Profile Generator

A simple Streamlit web app for the British Sociological Association regional event:

**Educating the Non-Traditional Learner: The Want, the Need, and the Demand for Inclusive Learning in the 21st Century**

Event: 3 September 2026, 10:00–15:00  
Venue: Aston Campus Event Centre, Birmingham, UK

## What attendees do

1. Upload a headshot.
2. Enter their name.
3. Click **Create My Profile**.
4. Download the generated PNG for LinkedIn, WhatsApp or other social media.

## Deploy

This app is designed for Streamlit Community Cloud.

- Put this folder into a GitHub repository.
- The repository must contain `app.py`, `requirements.txt`, and the `assets` folder.
- Deploy `app.py` from Streamlit Community Cloud.
- Choose a custom subdomain such as `bsa-inclusive-learning-profile` if available.

The app does not intentionally write uploaded participant photos to disk or a database.
